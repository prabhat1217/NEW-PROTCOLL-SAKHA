PROTOCOL SAKHA - APK (મોબાઈલ) અને EXE (PC) બનાવવા માટે પ્રોજેક્ટ
==================================================================

આ ZIP માં શું છે
  www\index.html                  -> સુધારેલી મુખ્ય HTML (આ જ એપની અંદર ચાલશે)
  PROTOCOL-SAKHA-standalone.html  -> એ જ ફાઇલ, સીધી બ્રાઉઝરમાં ખોલવા માટે
  PROTOCOL-SAKHA-ICON.png         -> તમારો ફોટો (એપ આઇકન)
  build\icon.ico, assets\         -> APK/EXE ના આઇકન અને સ્પ્લેશ (તમારા ફોટામાંથી બનેલા)
  electron\, capacitor.config.json, scripts\ -> બિલ્ડ ફાઇલો (બદલવાની જરૂર નથી)

એપનું નામ: PROTOCOL SAKHA   |   આઇકન: તમારો ફોટો (APK + EXE બંનેમાં)

------------------------------------------------------------------
રીત 1 (સૌથી સહેલી, PC માં કંઈ install નહીં): GitHub થી ઓનલાઇન બિલ્ડ
  1. github.com પર ફ્રી account બનાવો -> New repository (Private રાખો).
  2. આ ZIP ની બધી ફાઇલો (".github" ફોલ્ડર સહિત) upload કરો.
  3. Actions ટેબ -> "Build PROTOCOL SAKHA (APK + EXE)" -> Run workflow.
  4. 10-15 મિનિટ પછી Artifacts માંથી ડાઉનલોડ કરો:
        PROTOCOL-SAKHA-APK  (PROTOCOL-SAKHA.apk)
        PROTOCOL-SAKHA-EXE  (Setup.exe + Portable.exe)

રીત 2: Windows PC માં EXE
  - Node.js (LTS) install કરો -> ZIP extract કરો -> "1-BUILD-EXE.bat" પર Right click ->
    "Run as administrator". (ઇન્ટરનેટ જરૂરી.) EXE "dist" ફોલ્ડરમાં મળશે.

રીત 3: Windows PC માં APK
  - Node.js LTS + JDK 17 + Android Studio (Android SDK) install કરો.
  - "2-BUILD-APK.bat" ચલાવો -> "dist\PROTOCOL-SAKHA.apk".
  - મોબાઈલમાં APK નાખી install કરો ("Unknown sources" ની પરવાનગી આપવી પડશે).

    મુખ્ય પૃષ્ઠ પર બે વાર દબાવવાથી એપ બંધ થાય.
  - ડ્રોપડાઉન (select) ની યાદીમાં સફેદ બેકગ્રાઉન્ડ પર સફેદ અક્ષર દેખાતા નહોતા - સુધાર્યું.
  - યાદીમાં હોદ્દા પ્રમાણે ફિલ્ટર; શોધમાં ગુજરાતી અને અંગ્રેજી અંક બંને ચાલે.
  - મોબાઈલ નંબર પર ટેપ કરતાં કૉલ, અને 💬 થી WhatsApp.
  - Conflict / Leave / Settings વગેરે સ્ક્રીનનું ટાઇટલ ખોટું આવતું હતું - સુધાર્યું.
  - PDF ની ફાઇલના નામમાં ગુજરાતી અક્ષરો ઉડી જતા હતા - સુધાર્યું. "સુચના" -> "સૂચના", "ગુરૂવાર" -> "ગુરુવાર".
  - "બધા જુઓ" અને સાઇડબારનું "લોગ આઉટ" હવે સાચે કામ કરે છે.

નવું (ત્રીજા રાઉન્ડમાં): સ્ટેશન માંગણી + ઓટો રોટેશન બોર્ડ
  - સાઇડબાર "સ્ટેશન માંગણી" ખોલો. ડાબી બાજુ: પોલીસ સ્ટેશન (અને જોઈએ તો રૂટ / પોઈન્ટ) પસંદ કરો,
    PSI / ASI / HC / PC ની સંખ્યા લખો, "OK" દબાવો -> નામ રોટેશન મુજબ આપોઆપ આવી જશે.
  - જમણી બાજુ ડિસ્પ્લે બોર્ડ: દરેક સ્ટેશનનું અલગ કાર્ડ, નીચે હોદ્દા પ્રમાણે નામ સીધી લાઇનમાં.
    બીજું સ્ટેશન પસંદ કરી OK કરો તો તેની અલગ યાદી નીચે ઉમેરાય.
  - રોટેશન: જેને સૌથી લાંબા સમયથી ડ્યુટી ન મળી હોય તે પહેલા; રજા / તાલીમ / Unavailable વાળા બાકાત.
    એક જ દિવસે એક કર્મચારી બે સ્ટેશનમાં ન આવે.
  - 🔄 = બીજા નામ, ✏️ = સંખ્યા સુધારો, 🗑️ = કાઢો; નામ પર ટેપ કરી બીજું નામ પસંદ કરી શકાય.
  - 📷 ફોટો (PNG) બટનથી બોર્ડનો ફોટો સેવ / શેર; 📺 ફુલ સ્ક્રીન ડિસ્પ્લે; 💬 WhatsApp ટેક્સ્ટ.
  - દરેક તારીખનું બોર્ડ અલગ સેવ થાય છે (ઉપરની તારીખ બદલો).
  - જૂની પોઈન્ટવાર ફાળવણી બોર્ડના નીચેના બટનમાં છે.

નવું (ચોથા રાઉન્ડમાં): ડેટા સુરક્ષા, અપડેટ, કેલેન્ડર અને વધુ
  ડેટા હંમેશા સલામત
  - EXE (Portable): ડેટા EXE ની બાજુના "PROTOCOL-SAKHA-DATA" ફોલ્ડરમાં આપમેળે સેવ થાય છે.
    EXE + આ ફોલ્ડર પેનડ્રાઈવમાં લઈ જાઓ તો બીજા PC પર ડેટા એમ જ રહે.
  - EXE (Setup): ડેટા Documents\PROTOCOL-SAKHA-DATA માં સેવ થાય છે. Uninstall કરવાથી ડેટા ડિલીટ થતો નથી.
    દરરોજની બેકઅપ કૉપી (છેલ્લી 30) "backups" ફોલ્ડરમાં રહે છે. નવા PC પર ફોલ્ડર કૉપી કરી દો.
  - APK: દરેક બિલ્ડ એક જ ચાવીથી સાઇન થાય છે, એટલે નવી APK જૂની ઉપર સીધી Install કરો (Uninstall કરવાની જરૂર નથી)
    અને ડેટા એમ જ રહે. જો Uninstall કરવો પડે તો "ડેટા રાખો / Keep data" પસંદ કરો.
    ઉપરાંત ફોનના Documents\PROTOCOL-SAKHA ફોલ્ડરમાં ઓટો બેકઅપ ફાઇલ બને છે; નવી Install પછી એપ પૂછશે "પહેલાનો ડેટા
    મળ્યો, Restore કરવો છે?". (કેટલાક ફોનમાં આ ફોલ્ડર પરવાનગીથી ન બને તો "ડેટા સુરક્ષા" સ્ક્રીનથી બેકઅપ ફાઇલ
    WhatsApp / Drive માં શેર કરતા રહો.)
  - સાઇડબાર -> ડેટા અને સેટિંગ્સ -> "ડેટા સુરક્ષા અને એપ અપડેટ".
  APK/EXE વારંવાર બનાવ્યા વગર અપડેટ
  - નવી HTML (app.html) મળે ત્યારે "ડેટા સુરક્ષા અને એપ અપડેટ" માંથી ફાઇલ પસંદ કરો -> એપ અપડેટ થઈ જશે, ડેટા એમ જ રહેશે.
    (ઓનલાઇન લિંક આપી ત્યાંથી પણ અપડેટ ચેક કરી શકાય. મૂળ વર્ઝન પર પાછા જવાનું બટન પણ છે.)
  ઓફલાઇન + ઓનલાઇન: એપ બંને પર ચાલે. (ઇન્ટરનેટ માત્ર WhatsApp / ઓનલાઇન અપડેટ માટે જોઈએ.)
  કર્મચારી કમી કરવા
  - કર્મચારી યાદી -> નામ સામે "✏️ સુધારો" -> "🚪 કમી કરો" (બદલી / નિવૃત્ત / છૂટા + તારીખ + નોંધ).
    "કમી કરેલ કર્મચારી" સ્ક્રીનમાંથી ગમે ત્યારે "↩️ પાછા લાવો". જૂના રેકોર્ડમાં નામ એમ જ રહે.
  રજા કેલેન્ડર (2027, 2028... જાતે)
  - વર્ષ / મહિનો પસંદ કરો, "➕ રજા / મારી નોંધ ઉમેરો" (જાહેર / મરજીયાત / નોંધ, "દર વર્ષે" ટિક પણ) અને કોઈ પણ રજા "🗑️ કાઢો".
  - 15 ઑગસ્ટ, 26 જાન્યુઆરી જેવી નક્કી તારીખની રજાઓ દરેક વર્ષે આપોઆપ આવે; તહેવારો (દિવાળી વગેરે) જાતે ઉમેરવા.
  સાઇડબાર મેનુ (GujCop જેવું): મુખ્ય વિભાગો પર ટેપ કરતાં નીચે વિકલ્પો ખૂલે; ફોનમાં ડાબી બાજુથી સ્લાઇડ થઈને ખૂલે.
  તારીખ મુજબ રેકોર્ડ: રિપોર્ટ્સ / રેકોર્ડ -> "તારીખ મુજબ રેકોર્ડ" (બોર્ડ ખોલો / આજે કૉપી / કાઢો). બધી ફાળવણી તારીખ પ્રમાણે સેવ.
  ગુજરાતી ટાઇપિંગ: અંગ્રેજી અક્ષરોથી લખો (દા.ત. shri Raajesh bhai patel -> શ્રી રાજેશ ભાઈ પટેલ). ટોપ બારમાં "ગુ ✓" ચાલુ/બંધ,
    તેને લાંબો સમય દબાવો તો માર્ગદર્શન ખુલે. ટ, ઠ, ડ, ઢ, ણ માટે મોટા અક્ષર (T, Th, D, Dh, N).
  સુરક્ષા નોંધ: android-signing\protocol-sakha.keystore એપની સહી છે - આ ZIP / ફાઇલ કોઈને ન આપો. ખોવાય નહીં તે માટે કૉપી રાખો.

      ટેકનિકલ સંપર્ક જાતે લખો. ફોન / ઈ-મેલ / સરનામું હેડરમાં દેખાય; બાકીનું બોર્ડ, હુકમ અને WhatsApp માં.

  📄 હુકમ (PDF): સ્ટેશન માંગણી બોર્ડમાં "📄 હુકમ" -> સત્તાવાર A4 બંદોબસ્ત હુકમ (જા.નં., તારીખ, સ્ટેશનવાર નામ, બકલ, મોબાઈલ, સહી).
  🔁 નામ બદલો: નામ પર ટેપ -> નવું નામ -> "જૂનાને રજા મૂકો" + કારણ -> બદલો. બદલાવની નોંધ કાર્ડ, ફોટો અને હુકમમાં આવે;

  🎬 ડેમો મોડ: સાહેબને બતાવતી વખતે કાલ્પનિક નામો; વાસ્તવિક ડેટા સાચવાય, "ડેમો બંધ કરો" થી એક ટેપમાં પાછો.
  ✅ આપોઆપ ટેસ્ટ: `npm install` -> `npx playwright install chromium` -> `npm test` (20 તપાસ). GitHub થી બિલ્ડ કરો ત્યારે APK/EXE પહેલા
    ટેસ્ટ ચાલે છે; ટેસ્ટ નિષ્ફળ જાય તો બિલ્ડ અટકે. એપમાં ફેરફાર પછી આ ટેસ્ટ ફરી ચલાવો.

નવું (સાતમા રાઉન્ડમાં): ગુજરાતી ટાઇપિંગ સુધાર્યું
  - ફોનના Gboard (કે એવા) કીબોર્ડમાં પ્રિડિક્ટિવ/સજેશન સાથે ટાઇપ કરતી વખતે શબ્દો ભેગા થઈ જવાની
    કે અમુક શબ્દ ગુજરાતીમાં ન બદલાવાની તકલીફ હતી — તેનું કારણ પકડી સુધારી દીધું છે.
  - સામાન્ય ટાઇપિંગ (અક્ષરે-અક્ષર) અને Gboard જેવું પ્રિડિક્ટિવ ટાઇપિંગ, બંને હવે અલગ-અલગ રીતે સાચવીને
    બરાબર ગુજરાતીમાં ફેરવાય છે.

નવું (આઠમા રાઉન્ડમાં): સાઇડ મેનુ, જોડી (કારપૂલ) ફીચર
  📱 સાઇડ મેનુ: નાના ફોન સ્ક્રીનમાં એક મોટું મેનુ (દા.ત. "ડેટા અને સેટિંગ્સ") ખોલો ત્યારે તેની નીચેના મેનુ
    સ્ક્રીનની બહાર જતા રહેતા હતા, જેથી બંધ કર્યા વગર બીજું મેનુ ખોલવું અઘરું લાગતું. હવે મેનુ ખોલો એટલે
    તે આપોઆપ ઉપર સ્ક્રોલ થઈને દેખાય છે — સ્ક્રોલ કરીને કોઈ પણ મેનુ સીધું ખોલી શકાય, બંધ કરવાની જરૂર નથી.
  🚗 જોડી (કારપૂલ) ફીચર: બે કર્મચારી એક વાહનમાં સાથે આવતા હોય તો રોટેશનમાં તેમને સાથે જ ફાળવવા.
    - કર્મચારી યાદી -> નામ સામે "✏️ સુધારો" -> "🚗 જોડી ભાગીદાર" ડ્રોપડાઉનમાંથી બીજા કર્મચારીનું નામ પસંદ કરો -> સેવ કરો.
    - હવે રોટેશનમાં એકનો વારો આવે ત્યારે, જગ્યા હોય તો (એ સ્ટેશનમાં તેના હોદ્દાની જરૂરિયાત ખાલી હોય તો)
      બીજો પણ આપોઆપ સાથે જ ફાળવાશે — બોર્ડમાં તેના નામ સામે 🚗 નિશાન દેખાશે.
    - જગ્યા ન હોય (દા.ત. ફક્ત 1 PC ની જરૂરિયાત અને બંને PC હોય) તો ફક્ત એક જ ફાળવાશે; સંખ્યા 2 કે વધુ
      રાખો તો બંને સાથે આવવાની શક્યતા વધે.
    - જોડી તોડવા એ જ ડ્રોપડાઉનમાંથી "— કોઈ નહીં —" પસંદ કરો.
    - કર્મચારીને "કમી" કરો ત્યારે તેની જોડી આપોઆપ તૂટી જાય છે.
  🧪 ટેસ્ટ: 20 માંથી 20 આપોઆપ ટેસ્ટ પાસ થયા (જોડી ફીચર સહિત નવો ટેસ્ટ ઉમેરી શકાય, હાલ મેન્યુઅલી ચકાસ્યું છે).

મેનુ/ઓપ્શન જાતે ઉમેરવા કે કાઢવા હોય તો
  - સાઇડ મેનુ, બટન કે સ્ક્રીન કોડમાં લખેલા છે, એટલે હાલ એપની અંદરથી જાતે ઉમેરવા/કાઢવાનો વિકલ્પ નથી.
  - નવો મેનુ વિકલ્પ જોઈએ, કોઈ બટન કાઢવું હોય, કે નામ બદલવું હોય તો મને (આ ચેટમાં) ચોક્કસ જણાવો —
    "ક્યાં મેનુમાં", "શું ઉમેરવું/કાઢવું", "કેવું દેખાવું જોઈએ" — હું ફાઇલ સુધારી નવી ZIP આપીશ.
  - ડેટા સંબંધિત વસ્તુઓ (કર્મચારી, સ્ટેશન, રજા, ઓફિસ સેટિંગ્સ) જાતે જ ઉમેરવા/કાઢવા માટેની સ્ક્રીન પહેલેથી છે.

એપમાં કોઈ પ્રોબ્લેમ થાય તો શું કરવું
  1. પહેલા "ℹ️ એપ વિશે / મદદ" સ્ક્રીન જુઓ — મોટા ભાગની સમસ્યાનો ઉપાય ત્યાં ગુજરાતીમાં લખેલ છે.
  2. ડેટા સંબંધિત સમસ્યા (નામ ગાયબ, ખોટું દેખાય) -> એપ Uninstall ન કરો; પહેલા "🩺 સ્વ-તપાસ" સ્ક્રીન જુઓ,
     પછી "ડેટા સુરક્ષા" માંથી છેલ્લું બેકઅપ Restore કરો.
  3. સ્ક્રીન અટકે / ખોટી ખૂલે -> "⬅ પાછા" કે "🏠 મુખ્ય પૃષ્ઠ" દબાવો; મોબાઈલ Back બટન પણ કામ કરે છે.
  4. "ઓફિસ / હેડર સેટિંગ્સ" માં લખેલ ટેકનિકલ સંપર્ક નંબર પર કૉલ કરો (તમે એ સ્ક્રીનમાં નંબર ભરેલ હોવો જોઈએ).
  5. કોડ કે ફાઇલ સંબંધિત તકલીફ (એપ જ ન ખૂલે, નવું ફીચર જોઈએ, ફાઇલ સુધારવી છે) -> "🩺 સ્વ-તપાસ" માંથી
     "📦 ડાયગ્નોસ્ટિક ફાઇલ" બનાવી આ ચેટ (કે નવી Claude ચેટ) માં આ ZIP સાથે આપો — હું ફરી ચકાસી સુધારી આપીશ.
     આ ચેટ કાયમ સચવાય નહીં એટલે ZIP, keystore અને આ README ઓછામાં ઓછા બે જગ્યાએ (પેનડ્રાઈવ + Drive) સાચવો.

ડેટા વિશે (મહત્વનું)
  - બધો ડેટા તે ડિવાઇસમાં જ સેવ થાય છે. મોબાઈલ અને PC નો ડેટા અલગ રહેશે.
  - ડેટા ટ્રાન્સફર માટે: ડેટા મેનેજમેન્ટ -> Encrypted Backup લો -> બીજા ડિવાઇસમાં Restore કરો.
  - એપ 7 દિવસથી બેકઅપ ન લેવાય તો યાદ અપાવશે.
  - APK માં PDF / બેકઅપ ફાઇલ બને પછી "Share" સ્ક્રીન ખુલશે (WhatsApp, Drive, Files વગેરે).
